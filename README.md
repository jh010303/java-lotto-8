# java-lotto-precourse
## 구현 기능 목록

1. **로또 구매 기능**
   - 사용자가 금액을 입력하여 로또 구매
   - 1,000원당 1장의 로또 발급

2. **로또 번호 생성 기능**
   - 구매한 로또 수량만큼 자동으로 번호를 생성
   - 1부터 45까지의 중복 없는 6개의 번호 리스트 생성

3. **당첨 번호 입력 기능**
   - 사용자가 당첨 번호 6개와 보너스 번호 1개를 입력

4. **당첨 결과 계산 기능**
   - 구매한 로또와 당첨 번호를 비교하여 일치하는 개수를 계산
   - 일치하는 개수와 보너스 번호 일치 여부에 따라 등수를 결정
   - 각 등수별 당첨 통계 집계

5. **수익률 계산 기능**
   - 구매 금액 대비 당첨 금액의 비율을 계산하여 수익률을 표시

6. **입력값 검증 기능**
   - 입력 금액은 1,000 단위만 가능, 정수만 가능
   - 당첨 번호는 콤마를 기준으로 6개, 중복이 없어야 함
   - 보너스 번호는 당첨 번호와 중복되서는 안 됨, 정수만 가능

## 프로젝트 구조

### 1. 도메인 계층 (Domain Layer)
- **Lotto**: 로또 한 장을 표현하는 클래스, 6개의 번호를 가지며 당첨 번호와 비교하는 기능 제공
- **Lottos**: 여러 장의 로또를 관리하는 클래스, 싱글톤 패턴 적용
- **WinningLotto**: 당첨 번호와 보너스 번호를 관리하는 클래스, 싱글톤 패턴 적용
- **WinningRecord**: 당첨 결과를 기록하고 통계를 관리하는 클래스, 싱글톤 패턴 적용
- **RankReward**: 각 등수별 상금을 정의하는 열거형 클래스
- **LottoMachine**: 로또 구매 금액 관리, 로또 번호 생성, 수익률 계산 등의 기능 제공, 싱글톤 패턴 적용

### 2. 서비스 계층 (Service Layer)
- **LottoCommandService**: 로또 구매, 당첨 번호 설정, 당첨 통계 계산 등 명령 기능 제공
- **LottoQueryService**: 로또 수량, 로또 목록, 당첨 통계, 수익률 등 조회 기능 제공

### 3. 컨트롤러 계층 (Controller Layer)
- **LottoController**: 사용자 입력을 처리하고 서비스 계층과 뷰 계층을 연결하는 역할

### 4. 뷰 계층 (View Layer)
- **InputView**: 사용자로부터 입력을 받는 기능 제공
- **OutputView**: 결과를 사용자에게 출력하는 기능 제공
- **LottoViewCode**: 사용자에게 표시할 메시지를 정의하는 열거형 클래스

### 5. 상수 및 유틸리티 (Constants & Utilities)
- **LottoPrice**: 로또 가격 및 각 등수별 상금을 정의하는 상수 클래스
- **LottoVariable**: 로또 게임 규칙에 관련된 상수 정의 클래스
- **LottoWinner**: 당첨 등수와 조건을 정의하는 상수 클래스
- **LottoRegex**: 입력 검증에 사용되는 정규식 패턴 정의 클래스
- **LottoValidator**: 로또 번호 유효성 검사 기능 제공
- **Converter**: 문자열을 정수로 변환하는 등의 유틸리티 기능 제공

### 6. 예외 처리 (Exception Handling)
- **LottoErrorCode**: 로또 게임에서 발생할 수 있는 오류 메시지 정의
- **InputHandler**: 사용자 입력 처리 및 예외 발생 시 재시도 기능 제공
